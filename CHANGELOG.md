# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-16

### Added

- Initial release of ClassBridge Laravel package
- Session lifecycle orchestration with state machine
- Fake in-memory classroom provider driver
- Waiting room, join tokens, moderation, attendance, and recording services
- Multi-tenant session scoping via `forTenant()`
- Database migrations for sessions, participants, and phase-3 models
- Optional REST API routes and webhook ingestion
- Pest test suite with feature and unit coverage
